# 2차시 학습 내용

## Java Swing 이벤트 처리 학습
Swing GUI 프로그램에서 사용자와의 상호작용을 처리하는 이벤트 기반 프로그래밍을 학습하였다.

### 주요 이벤트 리스너
- ActionListener : 버튼 클릭 이벤트 처리
- MouseListener : 마우스 클릭 이벤트 처리
- MouseMotionListener : 마우스 이동 및 드래그 이벤트 처리
- MouseWheelListener : 마우스 휠 이벤트 처리

### 버튼 클릭 이벤트 구현
JButton을 클릭했을 때 클릭 횟수를 증가시키고 JLabel에 실시간으로 출력하는 기능을 구현하였다.

#### 구현 방식 비교
동일한 버튼 클릭 기능을 다양한 방식으로 구현하였다.
- 독립 클래스 방식
- 내부 클래스 방식
- 익명 클래스 방식
- 람다식 방식

이를 통해 Java의 이벤트 처리 구조와 코드 작성 방식의 차이를 학습하였다.

### 공유 카운터 구현
4개의 패널에 각각 버튼을 배치하고, 모든 버튼이 하나의 공유 카운터 값을 사용하도록 구현하였다.

구현 내용
- 버튼 클릭 시 카운터 증가
- JLabel에 현재 클릭 횟수 표시
- 여러 컴포넌트가 하나의 필드 변수를 공유

이를 통해 객체 간 데이터 공유와 이벤트 처리 방식을 학습하였다.

### 마우스 이벤트 처리 구현
MouseAdapter를 사용하지 않고 개별 이벤트 리스너 인터페이스를 직접 구현하여 마우스 이벤트를 처리하였다.

구현 기능
- 마우스 클릭 정보 출력
- 현재 마우스 위치 좌표 출력
- 마우스 휠 이동 거리 출력

출력 정보
- 클릭 정보 : 좌클릭(0), 우클릭(1), 가운데 클릭(2)
- 좌표 정보 : 현재 마우스 위치 (x, y)
- 휠 정보 : 휠 이동 거리

### 레이아웃 구성
화면 구성에 다양한 레이아웃 매니저를 활용하였다.
- BorderLayout
- GridLayout

구성 방식
- WEST 영역 : 이벤트 정보 출력
- CENTER 영역 : 마우스 이벤트 처리 패널
